# Pre-Generation Checklist

Before generating Java code, confirm:

- [ ] Functional requirement documented and understood
- [ ] Target SR module identified ([module-map.md](../module-map.md))
- [ ] Platform/Product/Solution placement decided
- [ ] Domain entities and relationships identified
- [ ] OpenAPI contract drafted or confirmed
- [ ] Figma/screen mapping complete (if UI-driven)
- [ ] Business rules listed with IDs
- [ ] Events and integrations identified
- [ ] Traceability matrix started

Do not generate code until all Critical items are checked.
